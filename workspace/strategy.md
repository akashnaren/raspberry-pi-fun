# Strategy

The board asked for a browser Office, not another converter.

Flagship is **Meridian Office**. Docs first — headings, lists, find, print. Sheets is a local grid. Slides is a short deck. Paste → CSV is a catalogue tidy tool. No formulas. No AI write. No animation engine.

Timezone Buddy already shipped. It stays in the catalogue.

No accounts. No payments. No uploads. No chat. That is permanent.

This week: a stranger can poke Docs and tidy a messy table in under a minute. The HDMI stage shows that suite, not Timezone Buddy.
